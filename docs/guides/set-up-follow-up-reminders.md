# Set up follow-up reminders

**This guide shows how to attach a follow-up reminder to a contact, choose a template and priority, and manage it through the Today / Upcoming / Overdue views.** See [Reminders](../features/reminders.md) for the feature reference.

## Create a reminder

1. Open the contact you want to follow up with.
2. Choose **Add reminder**.
3. Pick a template — **Follow up**, **Send quote**, or **Book call** — or type a custom title.
4. Set the **due date and time**.
5. Set a **priority** so urgent items stand out.
6. Save.

## Allow notifications (Android)

The first time you set a reminder on Android, allow notifications when prompted. SnapContact requests this permission at the moment it's needed, not at launch. Once allowed, due reminders fire a notification and update the app badge. On the web, due reminders surface in your views instead of OS notifications.

## Work your day

Use the three views to stay on top of follow-ups:

- **Today** — your action list for right now.
- **Upcoming** — what's scheduled ahead.
- **Overdue** — anything past due and not done, kept visible so it doesn't slip.

From any view you can mark a reminder **done**, **snooze** it, or **reschedule**.

## Build a habit

The capture-then-schedule loop is what keeps leads warm: every time you save a contact — by scan, WhatsApp, import, or by hand — add a reminder for the next step before you move on. A tagged contact with a dated follow-up is a lead you'll actually act on.

## Frequently asked questions

**Do I have to allow notifications?** Only if you want OS notifications on Android. Without them, reminders still appear in the Today/Upcoming/Overdue views.

**Can I reschedule a reminder?** Yes — mark done, snooze, or reschedule from any view.

**Are there reminder templates?** Yes: Follow up, Send quote, Book call, plus custom titles.

**Will overdue reminders disappear?** No — they stay in the Overdue view until you act on them.
